## Summary

**Defect found** in `source/collator.py`'s `PackedBatchCollator`. It packs `DOCUMENTS_PER_PACK=4` independent chat documents into one training sequence and correctly resets `position_ids` to 0 at each document boundary (and even computes `document_lengths`), but then builds `attention_mask = torch.ones_like(input_ids)` — a plain causal mask with **no document isolation**. `document_lengths` was otherwise unused anywhere in `source/`, confirming the isolation step was dropped.

I empirically confirmed the effect: with the same trailing document, changing an *earlier* packed document's content changed the later document's logits by up to ~9.9 (mean ~1.6) — real leakage, not noise. This meant ~75% of packed training tokens (every document after the first in a pack) were trained with attention to unrelated prior conversations, plus RoPE received nonsensical negative relative-position offsets across the reset boundaries — a mismatch versus the isolated, single-document evaluation path.

**Fix**: build a block-diagonal boolean causal mask from `document_lengths` so each document only attends to itself. Validated end-to-end (forward, backward, optimizer step) against the real model/adapter/data at stable scales; confirmed the leakage metric drops to near-zero residual (bf16 noise level) with the fix. Larger-scale runs hit intermittent CUDA "illegal instruction" errors in this sandbox, but I confirmed these reproduce identically with the pristine, unmodified original code — pre-existing GPU/driver flakiness in this session, unrelated to the fix.
