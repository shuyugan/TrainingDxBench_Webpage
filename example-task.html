Example task: padding-free chat packing

A training run with normal loss curves silently allows independent conversations to attend across packed boundaries.

padding-free-chat-packing model failed
SFT padding-free packing attention masks label alignment Qwen2.5-0.5B
Flawed
  1. attention_mask = torch.ones_like(input_ids)

    The dense mask disables packed-segment detection, allowing later documents to attend to unrelated earlier documents.

  2. labels = input_ids.clone()

    Reset positions remain supervised, causing each document to predict the first token of the next document.

→
Corrected
  1. - "attention_mask": torch.ones_like(input_ids),

    Removing the dense mask lets reset position IDs define independent packed segments.

  2. labels[position_ids == 0] = -100

    Ignoring reset-position labels removes cross-document boundary targets.
